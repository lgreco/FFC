## Section 4 — Engine Inspection (Lycoming IO-360-C1C6)

### 4A — Visual & Leak Check
- [ ] Inspect engine compartment for oil leaks at all gasket surfaces, fittings, and hose connections
- [ ] Inspect fuel injection lines and clamps (recurring AD item — verify current compliance)
- [ ] Inspect exhaust system for cracks, loose clamps, and security — note muffler history (replaced 2009, 2011)
- [ ] Inspect all baffles for cracks and proper seating
- [ ] Inspect air filter for condition and security
- [ ] Inspect firewall penetrations and seals
- [ ] Check oil level and inspect oil for color, contamination, metallic particles

### 4B — Compression Test (differential)
- [ ] Cylinder #1 differential compression: _______ / 80
- [ ] Cylinder #2 differential compression: _______ / 80
- [ ] Cylinder #3 differential compression: _______ / 80
- [ ] Cylinder #4 differential compression: _______ / 80
- [ ] Note location and magnitude of any leakage (rings, valves, case)
- [ ] Compare to last annual values (#1 78, #2 78, #3 76, #4 78 — all /80)

### 4C — Borescope Inspection
- [ ] Borescope all four cylinders — inspect barrel walls, piston crowns, and valve faces
- [ ] Note any scoring, rust, corrosion, or abnormal carbon deposits
- [ ] Inspect intake valve stems and seats
- [ ] Inspect exhaust valve stems and seats

### 4D — Oil Analysis
- [ ] Obtain and review all oil sample (SOAP) reports since 2023 overhaul
- [ ] If no recent sample available, pull sample during inspection and send to lab before closing
- [ ] Review trends in iron, chrome, aluminum, copper, lead, silicon — flag any upward trends
- [ ] Confirm oil consumption rate with seller (~1 qt/10-12 hrs claimed)

### 4E — Ignition System
- [ ] Inspect new magnetos (2025) — verify correct timing (20° BTDC per log)
- [ ] Perform magneto drop check during ground run — note RPM drop each side
- [ ] Inspect spark plugs — remove and inspect all 8 for wear, deposits, and gap
- [ ] Inspect ignition harness and leads for condition and security
- [ ] Verify new ignition switch installation (2024) — function check

### 4F — Fuel System
- [ ] Verify new electric fuel pump installation (2024) — function check on/off
- [ ] Inspect fuel injection servo (Precision RSA-5AD1, installed 2011 — verify STC/AD status)
- [ ] Inspect all fuel injection nozzles for cleanliness
- [ ] Inspect fuel selector valve for proper operation through all positions
- [ ] Check fuel strainers and gascolator for contamination
- [ ] Inspect fuel tank vents for obstructions
- [ ] Drain and sample fuel from all sumps

### 4G — Cooling & Induction
- [ ] Inspect oil cooler for leaks and condition
- [ ] Inspect oil cooler hoses and fittings
- [ ] Inspect alternate air door and mechanism
- [ ] Inspect induction air system for cracks and security

### 4H — Engine Accessories
- [ ] Inspect PlanePower alternator (2025) — verify output voltage during ground run
- [ ] Inspect voltage regulator (2025)
- [ ] Inspect engine mount for cracks and security
- [ ] Inspect engine shock mounts for deterioration
- [ ] Verify block heater installation and condition

## Section 11 — Ground Run & Flight Check

### 11A — Ground Run
- [ ] Cold start — note ease of start and initial oil pressure rise
- [ ] Monitor CHT and EGT on all cylinders during warm-up
- [ ] Check oil pressure (normal: 55-95 PSI at cruise)
- [ ] Check oil temperature
- [ ] Run-up at 1800 RPM — check each magneto (max 125 RPM drop; max 50 RPM differential)
- [ ] Check carburetor heat / alternate air
- [ ] Check throttle and mixture cable full travel
- [ ] Check fuel pump on/off — note pressure change
- [ ] Verify gear warning horn sounds with throttle at idle and gear up (squat switch test per POH)
- [ ] Check brakes — both sides independently and together

### 11B — Check Flight (highly recommended)
- [ ] Verify all avionics and navigation equipment functional in flight
- [ ] Check VSpeeds — Vy, Vx, Va, Vfe, Vle, Vlo all within expected range
- [ ] Extend and retract flaps at each detent in flight
- [ ] Perform gear extension/retraction in flight — verify times and indicator function
- [ ] Perform stall series — note stall warning and characteristics
- [ ] Check trim in all axes
- [ ] Verify pitot heat function in flight
- [ ] Check autopilot if installed
- [ ] Monitor all engine gauges throughout flight for anomalies
- [ ] Check heated pitot tube function
